# diskrepair playbooks

Generated by `diskrepair export --for system-rescuer`. Each playbook prints a
procedure and never runs one. The text matches diskrepair's own playbooks except
where the stick's rules apply: workstation-only steps show no command, a step whose
program the stick lacks names what to use instead, and citations of diskrepair's
planning documents are spelled out so each file stands alone.
The rescue stick's own rules take precedence over these playbooks; steps marked owner-attended workstation only are not run from the stick.
